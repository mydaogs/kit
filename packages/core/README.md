# @mydaogs/core

**Zero-dependency isomorphic primitives**

The bigint JSON wire protocol, a bigint-safe stable hash, typed dynamic route paths, and shared type helpers. No dependencies at all, so anything may depend on it.

## Documentation

These docs are the single source of truth for this package and ship with it:

- [`bigint-serialization-rules.md`](./bigint-serialization-rules.md)

## Install

```bash
pnpm add @mydaogs/core
```

Peer dependencies are listed in `package.json` and are deliberately not bundled
